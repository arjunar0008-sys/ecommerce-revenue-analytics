# E‑commerce Revenue Analytics Dashboard (Power BI)

This Power BI dashboard analyzes e‑commerce revenue trends, product performance, order distribution, category insights, and customer satisfaction metrics.

## 📊 Tools Used
- Power BI
- Power Query
- DAX
- Excel (data source)

## 🧠 Key Insights
- Monthly revenue trends  
- Top‑selling products and categories  
- Order distribution by region and category  
- Average rating and customer satisfaction  
- Quantity sold and AOV (Average Order Value)

## 📁 Files Included
- `Ecommerce_Revenue_Analytics.pbix`
- Supporting data files (if any)

## 🧰 Dashboard Features
- Slicers for Category, City, State, Month  
- KPI cards for revenue, orders, quantity sold, AOV  
- Trend charts for monthly revenue  
- Product‑level insights with top 10 performers  
- Clean layout for management reporting
